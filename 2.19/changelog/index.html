    All notable changes are recorded here. Beginning after v1.3.0, this file is generated by Python Semantic Release from Conventional Commit messages.

    Bug Fixes¶

    • packaging: Rebuild the PyInstaller bootloader from source on Windows (d379b7f)

    Chores¶

    • Ignore the pyinstaller source pin file the Windows build writes (8c3bfa6)

    Documentation¶

    • Explain the Windows antivirus false positive (756e581)

    v2.19.0 (2026-08-20)¶

    Features¶

    • timers: Collapsible group headers in the Timers window (74d8529)

    v2.18.1 (2026-08-20)¶

    Bug Fixes¶

    • discord: Create the Discord window with an alpha channel (ea32c5a)

    Documentation¶

    • plugins: Finish the sweep — three more pages said "next launch" (ede1392)

    • plugins: Say that add-ons load and unload without a restart (123f43b)

    v2.18.0 (2026-08-20)¶

    Bug Fixes¶

    • plugins: Keep a plugin's timer mutations on the driver thread (2d7a185)

    • plugins: Re-render the manager row when a toggle takes effect (6a36836)

    • plugins: Report what an install actually did, and stop tray takeovers (f610bab)

    Documentation¶

    • plugins: The Plugins page hint says what a toggle now does (d4c76c9)

    Features¶

    • plugins: Activate and deactivate plugins without a restart (9b48f55)

    • plugins: Build and destroy plugin windows and pages without a restart (2c117b7)

    • plugins: Let a plugin's surfaces follow it, and retry a failed activate (72b26e7)

    Bug Fixes¶

    • plugins: Never delete a registry row the move cannot disambiguate (d667324)

    • plugins: Recognise a post-move settings document without a marker (836b3af)
